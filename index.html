ReverseFiascko

ReverseFiascko is a lightweight Unity Editor toolkit I created to help protect my games against reverse engineering. It analyzes project settings, applies recommended protection configurations, and validates builds to identify potential security issues. It is designed to make reverse engineering more difficult while keeping the process simple, with no external dependencies and no runtime overhead.
